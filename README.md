# sensenova-loop-9B-4-bit-quanitzed-tests
SenseNova Loop-9B is designed to be efficient. The official 4-bit quantized weights are about 4.9 GB, and it can run with under 10 GB of VRAM, making CPU inference possible. However, you must be careful with dependencies, as a full CUDA-enabled PyTorch install can consume a significant portion of your 14 GB disk space.
